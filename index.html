How to use this widget
  1. Click + Add post to add a new post to your grid.
  2. Paste an image URL (from Google Drive, Dropbox, Unsplash, Canva etc.) into the Image URL field.
  3. Add your caption, scheduled date, and status.
  4. In the Grid preview tab, drag posts to reorder your feed layout.
  5. Hover over any grid cell to preview the caption.
  6. Click Save grid to save everything in your browser.
  7. Upload this HTML file to tiiny.host (free) to get a URL you can embed in Notion using /embed.

Image URL tips
  1. Canva: export image → share → get link → copy direct image link
  2. Google Drive: share file → anyone with link → copy URL then change /view to /uc?export=view
  3. Unsplash: right-click image → copy image address
  4. Dropbox: share → copy link → change dl=0 to raw=1
